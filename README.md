# Tu Conta en Línea

Este proyecto es una **prueba técnica frontend** desarrollada con **HTML, CSS y JavaScript puro**, sin uso de frameworks ni librerías de UI.
El objetivo fue **demostrar dominio de CSS nativo, estructuración de estilos, interactividad básica en JavaScript y buenas prácticas de SEO desde HTML.**

La temática simula un sitio de servicios contables, pero el foco del proyecto está en la **implementación técnica**, no en el producto en sí.

## Objetivos técnicos del proyecto

- Demostrar habilidades en CSS avanzado:
   - Variables CSS (design tokens)
   - Sistema de temas (light / dark mode)
   - Componentes reutilizables
   - Animaciones y transiciones
   - Layout responsive sin frameworks
- Implementar **interactividad con JavaScript puro:**
   - Manejo de modales
   - Toggle de tema
   - Manipulación directa del DOM
-Aplicar **SEO nativo**:
   - Meta tags
   - Open Graph
   - Estructura semántica en HTML
- Mantener una estructura clara y mantenible en un proyecto sin tooling complejo.


## Estructura del proyecto


Asegúrate de descargar los siguientes archivos y colocarlos en la misma carpeta:

- ```index.html``` Contiene la estructura principal del sitio, etiquetas semánticas y configuración SEO.
- ```styles.css``` Estilos organizados mediante variables CSS, utilidades, componentes y secciones. Incluye soporte para modo oscuro y animaciones.
- ```main.js``` Lógica de interactividad (modal, cambio de tema, eventos).

## Requisitos

- Navegador web moderno (Chrome, Firefox, Edge, Safari).
- **Conexión a Internet:** Algunos recursos como fuentes y bibliotecas de iconos (Google Fonts y Font Awesome) se cargan desde Internet, por lo que necesitarás una conexión activa para visualizarlos correctamente.

## Cómo ejecutar el proyecto

1. Clona el repositorio o descarga los archivos.

2. Asegúrate de que ```index.html```, ```styles.css``` y ```main.js``` estén en la misma carpeta.

3. Abre `index.html` directamente en tu navegador.

No requiere instalación de dependencias ni proceso de build.
